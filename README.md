# Читалка: древние тексты без готовой трактовки

## Зачем этот проект

Цель — прочитать Библию (а затем Еноха, Юбилеи и другие древние тексты) так близко к сохранившемуся тексту, как это возможно, и на каждой странице видеть, **где кончается текст и начинается толкование**.

Это не ещё один перевод «как правильно». Читалка показывает:

- что написано (еврейский текст);
- что из этого можно перевести уверенно — и это переведено;
- где возможны несколько значений — там слово оставлено латиницей, а варианты раскрыты в карточке;
- что пока неизвестно — так и сказано;
- как это место понимают разные толкователи (традиция, Мауро Бильино и другие) — отдельно от перевода, с источником и оценкой того, на чём держится каждое утверждение.

Исходный замысел своими словами — в [docs/ЗАМЫСЕЛ.md](docs/ЗАМЫСЕЛ.md).

## Главное правило

> Слово переводится, только если **в этом месте** у него нет разумной альтернативы. Иначе — транслитерация и карточка с вариантами.

Имена и титулы божества (YHWH, Elohim и др.), имена людей и мест не переводятся никогда. Одно значение слова везде передаётся одним русским словом. Авторитет («так переводят», «так считают учёные») доказательством не считается — ни для традиционных, ни для альтернативных прочтений.

Полный свод — [ПРАВИЛА.md](ПРАВИЛА.md). Правила меняются только с вашего согласия.

## Как пользоваться читалкой

**Запуск:** ярлык «Читалка» в папке Bible. Откроется браузер с библиотекой книг. Интернет для чтения не нужен.

**Linux:** один раз выполните `sh app/install_linux.sh` — появится ярлык «Читалка» в меню приложений и на рабочем столе. Без ярлыка: `python3 app/server.py`. Нужен только Python 3. Папку Bible переносите целиком, вместе с «Книги Бильино».

**Телефон:** читалка опубликована как сайт: https://z1makoff.github.io/Bible/ — откройте в браузере телефона и добавьте на главный экран («Установить приложение» / «На экран „Домой“»). Уже открытые главы читаются и без интернета. Сайт обновляется сам после каждой отправки изменений в GitHub. Заметки и решения на телефоне хранятся в браузере телефона; перенос между телефоном и компьютером — в библиотеке, раздел «Ваши данные»: «Сохранить в файл» на одном устройстве, «Загрузить из файла» на другом (ничего не стирается, из двух версий записи остаётся более новая).

- **Библиотека.** Книги Ветхого Завета; у книги видно, сколько глав подготовлено и сколько вы прочитали. Кнопка «Продолжить» ведёт туда, где вы остановились.
- **Глава.** Русский текст. Латиница — слова, которые не переводятся; серым — слова, вставленные ради русской грамматики (в оригинале их нет); значок ◇ — грамматическая развилка (неоднозначна конструкция, а не слово). Переключатели «Еврейский» и «Синодальный» показывают слои под каждым стихом.
- **Карточка слова** (щелчок по слову): оригинал и грамматика; почему здесь так (переведено или нет и почему); засвидетельствованные значения с местами; трактовки; все места, где слово встречается; что пишут словари (как подсказка, не доказательство); ваша заметка.
- **Ваше решение для места.** Можно задать свой вариант перевода в конкретном месте — он сразу заменит текст. Claude не переносит такие решения в проект, пока вы не подтвердите, что решение настоящее, а не проба.
- **Переходы по ссылкам.** Ссылки в карточке ведут к другим местам; кнопка «← Вернуться» (или Backspace) возвращает к слову, с которого вы начали. Такие переходы не меняют место чтения.
- **«Отметить главу прочитанной»** — в начале и в конце главы; отметки видны в списке глав.

Всё ваше сохраняется сразу и не пропадает при закрытии: решения, заметки, место чтения, отметки, переключатели. Каждое изменение записывается в журнал, а раз в день читалка делает копию ваших данных (`user/backups/`).

## Как идёт работа

ИИ в программу не встроен. Главы готовит Claude в отдельных сессиях Claude Code: подбирает решения для новых слов, переводит по правилам, пишет трактовки с дословными цитатами из книг. Автоматическая проверка (`tools/check.py`) не пропускает главу, пока в ней есть хоть одно нарушение правил: слово без решения, перевод не тем словом, цитата, которой нет в книге. Вы читаете, спрашиваете и поправляете; ваше решение главнее.

- **Бытие, все 50 глав; Исход, все 40 глав; Левит 1–3**: перевод, словарь решений (2480 слов), трактовки Бильино и традиционные (Толковая Библия Лопухина) к спорным местам — всего 532.
- Источники: масоретский текст (Ленинградский кодекс, разметка Open Scriptures), Синодальный перевод, словари BDB, Strong, STEPBible — с паспортами версий и лицензий.

## Что из замысла пока не сделано

- **Отметки отличий Синодального** («сужено», «добавлено», «заменено» — правила, раздел 7): сейчас Синодальный показан просто текстом.
- **Другие древние свидетели** (Кумран, Септуагинта, самаритянский текст): их нет в источниках; разночтения упоминаются в пояснениях только по вторичным источникам.
- **Родственные языки** (аккадский, угаритский) — только через подсказки словарей.
- **Изменение значений во времени** и отдельный граф «утверждение → доказательство» шире, чем у трактовок.
- **Строгий режим** не нужен: по решению от 17 октября 2026 в программе один режим — переводится только то, у чего нет альтернативы.
- Новый Завет, Енох, Юбилеи — после Ветхого Завета.

## Устройство папок

| Папка или файл | Что это |
|---|---|
| `ПРАВИЛА.md` | Правила перевода и трактовок — единственный источник истины |
| `DATA.md` | Форматы файлов (для подготовки глав) |
| `CLAUDE.md` | Инструкция для Claude: как готовить главу |
| `docs/` | Замысел проекта |
| `app/` | Программа-читалка (запуск — `app/launch.vbs` на Windows, `app/launch.sh` на Linux) |
| `sources/` | Скачанные исходные тексты и словари с паспортами |
| `corpus/` | Корпус, собранный из исходников (пересобирается, в git не хранится) |
| `decisions/lexicon/` | Словарь решений: одно слово — один файл, значения и места-свидетельства |
| `translations/` | Перевод глав по словам |
| `interpretations/` | Трактовки: одна трактовка — один файл, с источником и оценками |
| `library/` | Каталог книг-источников трактовок; тексты в общественном достоянии (`texts/`) |
| `tools/` | Сборка корпуса, проверка, подготовка глав |
| `user/` | Ваши решения, заметки, место чтения, журнал и копии (пишет только читалка, в git не хранится) |

Книги Бильино лежат рядом, в папке `Книги Бильино`, и в проект не копируются: в трактовках — только короткие дословные отрывки.
