# Устройство данных

Справка для подготовки глав. Правила перевода — в [ПРАВИЛА.md](ПРАВИЛА.md); этот файл описывает только, где и в каком виде всё хранится.

## Папки

| Папка | Что внутри | Кто меняет |
|---|---|---|
| `sources/` | Скачанные исходники и их паспорта (`passport.json`: лицензия, версия, SHA-256) | никто — только `tools/fetch_sources.py` |
| `corpus/` | Корпус, собранный из исходников. Не хранится в git: пересобирается командой `python tools/build_corpus.py` | только сборка |
| `decisions/lexicon/` | Словарь решений: один файл на словарное слово | Claude, с подтверждения пользователя |
| `decisions/geez/` | Словарь решений геэза: один файл на статью Дильмана (`L…`) | Claude, с подтверждения пользователя |
| `translations/ot/<Книга>/<ггг>.json` | Перевод главы, по словам | Claude |
| `translations/1En/<ггг>.json` | Перевод главы 1 Еноха, по словам | Claude |
| `interpretations/` | Трактовки: один файл на трактовку | Claude, только с проверенным источником |
| `library/books.json` | Каталог книг-источников трактовок. Книги Бильино — вне репозитория, в `../Книги Бильино`; тексты в общественном достоянии — в `library/texts/` | Claude |
| `.cache/` | Извлечённый текст книг для поиска цитат. Не хранится в git | только `tools/books.py` |
| `user/` | Решения и заметки пользователя из читалки | читалка |
| `tools/` | Скрипты: загрузка, сборка, проверка | — |

## Корпус (`corpus/`)

- `ot/books.json` — 39 книг: `id` (OSIS), русское название, число глав.
- `ot/<Книга>/<ггг>.json` — глава. У стиха: `ref` (`Gen.1.1`), `n`, `words`, `syn` (синодальные стихи), иногда `break` (`pe`/`samekh` — масоретские разделы).
- Слово: `id` (номер слова в OSHB, уникален во всём ВЗ), `text`, `tr` (механическая транслитерация), `lang` (`H` — еврейский, `A` — арамейский), `segs` (морфемы: `t`, `lemma`, `prefix`, `morph`), а также `maqqef`, `ketiv` и `qere` (список прочитываемых слов), `sourceNote`.
- `syn`: `{c, v, text, exact}`. `exact: false` — границы стихов не совпадают.
- `ot/synodal-only.json` — стихи, которые есть только в Синодальном (из Септуагинты).
- `lexemes.json` — словарные слова по ключу OSHB (`1254a`, `430`): еврейская форма, транслитерация, часть речи, число употреблений, статьи BDB, Strong и STEPBible. Это **аннотации**, а не доказательство.
- `occurrences.json` — для каждого ключа список `[стих, id слова]`.
- `build-report.json` — что не удалось сопоставить при сборке.

## Словарь решений (`decisions/lexicon/<ключ>.json`)

```json
{
  "key": "7307",
  "kind": "word",
  "display": "ruach",
  "senses": [
    {"id": "wind", "ru": "ветер", "stems": ["ветр", "ветер"],
     "gloss": "движение воздуха", "evidence": ["Gen.8.1", "Exod.10.13"]}
  ],
  "status": "draft",
  "notes": "",
  "history": [{"date": "2026-10-17", "by": "claude", "change": "создано"}]
}
```

- `kind`: `word` (обычное слово), `name` (имя человека, место, народ), `divine` (имя или титул божества), `function` (служебное слово), `keep` (не переводится нигде: значение не установлено или не выбирается; причина — в `notes`, известные значения — в `senses` для карточки).
- `display` — латинская форма для текста, когда слово не переводится (правила, раздел 2). Для `name` и `divine` слово никогда не переводится.
- `displayForms` (необязательно) — другие допустимые латинские формы того же слова, например множественное число (`keruvim` при `display: keruv`).
- `senses` — засвидетельствованные значения. `ru` — русское слово для этого значения, одно на всю Библию (раздел 3). `stems` — основы, по которым проверка узнаёт это слово в любом падеже. `evidence` — места, где значение видно; проверка требует, чтобы слово там действительно стояло.
- `status`: `draft` (подготовлено Claude) или `approved` (подтверждено пользователем).

## Перевод главы (`translations/ot/<Книга>/<ггг>.json`)

```json
{
  "book": "Gen", "chapter": 1, "rules": "1.0", "status": "draft",
  "verses": [
    {"n": 1,
     "spans": [
       {"t": "В начале", "w": ["01xeN"], "s": "beginning", "g": "Конструкция допускает: «В начале…» или «В начале того, как…»"},
       {"t": "создал", "w": ["01Nvk"], "s": "create"},
       {"t": "Elohim", "w": ["01TyA"], "k": "lat"},
       {"t": "небеса", "w": ["01TSc"], "s": "sky"},
       {"t": "и", "w": ["01k5P"], "k": "fn"},
       {"t": "землю", "w": ["01nPh"], "s": "land"},
       {"t": ".", "k": "p"}
     ],
     "omit": {"01vuQ": "et"},
     "places": {"01TyA": {"fits": [], "why": "Имя божества — не переводится (правила, раздел 2)"}}
    }
  ]
}
```

- `spans` — русский текст стиха по порядку. У каждого фрагмента: `t` (текст), `w` (номера еврейских слов; одно слово может дать несколько фрагментов, например «и» + «ruach»).
- `k` — вид фрагмента: не указан — перевод; `lat` — слово оставлено в транслитерации; `fn` — служебное слово, приставка или местоименное окончание («и», «в», «его»); `ins` — вставлено ради русской грамматики, показывается серым; `p` — знак препинания.
- `s` — какое значение из словаря решений использовано. Обязательно для перевода.
- `g` — грамматический выбор (◇): какие разборы конструкции возможны.
- `x` — исключение из словаря решений в этом месте, с причиной (раздел 3).
- `omit` — еврейские слова, которые не дают русского слова, с причиной (`et` — метка прямого дополнения).
- `places` — разбор места для карточки: `fits` — какие значения подходят здесь, `why` — почему переведено или нет.

## Трактовки (`interpretations/<id>.json`)

```json
{
  "id": "biglino-elohim",
  "tradition": "Мауро Бильино",
  "lemmas": ["430"],
  "places": ["Gen.1.1"],
  "claim": "Пересказ утверждения без усиления",
  "source": {"kind": "book", "book": "biglino-non-ce-creazione", "chapter": "Concludendo",
             "quote": "дословный отрывок на языке книги, до 15 слов", "quoteRu": "его перевод", "checked": "2026-10-17"},
  "support": [
    {"claim": "Отдельное ключевое утверждение", "grade": "compatible",
     "for": ["Gen.1.26"], "against": ["Deut.4.35"], "note": "…"}
  ]
}
```

Источник (`source`): `kind` — `book`, `video` или `web`. Для книги: `book` — id из `library/books.json`, `quote` — дословный отрывок (проверка ищет его в файле книги, не обращая внимания на переносы, пробелы и кавычки), `quoteRu` (перевод отрывка; для русских книг не нужен), `chapter` или `section` (необязательно: глава книги или место своими словами, например «толкование на Быт 1:1»), `page` — только если у издания `pages: true`. Для видео: `title`, `url`, `time`. Для страницы: `title`, `url`.

Каталог книг: `folder` — папка с файлами (от корня проекта); у книги `id`, `title`, `author`, `publisher`, `year`, `isbn`, `lang`, `pages` (есть ли печатные номера страниц), `file` (в папке folder) или `path` (файл в проекте — для текстов в общественном достоянии, `library/texts/`), `sha256`, `url` (откуда взят текст).

`grade` — шкала из правил, раздел 6: `entailed`, `strong`, `supported`, `plausible`, `compatible`, `speculative`, `contradicted`. В интерфейсе показываются только русские названия.

## Файлы пользователя (`user/`)

Пишет только читалка. Ничего отсюда не удаляется молча.

- `decisions.json` — решения пользователя по местам: ключ `Gen.1.1:01Nvk` → `{text, reason, date, seenByClaude}`. В читалке такое решение заменяет фрагмент перевода. `seenByClaude: false` — Claude ещё не учёл его.
- `notes.json` — заметки: `lexeme:<ключ>`, `place:<стих>:<слово>`, `verse:<стих>`.
- `history.jsonl` — журнал всех изменений (что было, что стало, когда).
- `state.json` — место чтения, включённые слои и `returnTo` — слово, к которому ведёт кнопка «← Вернуться» после переходов по ссылкам из карточки (такие переходы место чтения не меняют).
- `progress.json` — прочитанные главы: `Gen.1` → `{date}`. Отметка ставится и снимается кнопкой в главе; изменения пишутся в `history.jsonl`.
- `backups/<дата>/` — копия всех файлов пользователя, раз в день при запуске читалки. Ничего не удаляется.

## Проверка

`python tools/check.py` — проверяет все решения, переводы и трактовки по правилам. Глава считается готовой, только если проверка проходит без ошибок. Одна глава: `python tools/check.py Gen 1` или `python tools/check.py 1En 1`. Сборка краткой записи: `python tools/compile_chapter.py 1En 1 путь/к/спецификации.txt`. Разбор главы по словам: `python tools/dump_chapter.py 1En 1`.

## Разметка Еноха: `morph/enoch/<ггг>.json`

Разбор 1 Еноха по словам: `{chapter, words}`, ключ в `words` — номер слова корпуса `e<ннннн>`. У слова: `status` (`auto` — тегер, не проверено; `unsure` — вопрос остаётся; `checked` — прочитано человеком или Opus), `segs` (`t`, `lemma` — ключ статьи в `corpus/geez-lexemes.json`, `prefix`, `morph`), `gram`, `alts` (другие статьи), `note`. Значение слова здесь не выбирается. Тегер `tools/enoch_tag.py` не перезаписывает файл, где есть что-то кроме `auto`. После правки — `python tools/build_enoch.py`, потом `python tools/check.py`.

## Словарь решений геэза (`decisions/geez/<ключ>.json`)

Та же схема, что у `decisions/lexicon`: `key`, `kind`, `display`, `displayForms`, `senses` (`id`, `ru`, `stems`, `gloss`, `evidence`), `status`, `notes`, `history`. Плюс два поля статьи Дильмана: `n` (номер) и `head` (заголовок геэзом). Ключ — `L…`, как в `corpus/geez-lexemes.json`, и он же имя файла. `n` и `head` должны совпадать со статьёй.

```json
{
  "key": "L1a2b",
  "n": "3907",
  "head": "ባረከ",
  "kind": "word",
  "display": "baraka",
  "senses": [
    {"id": "bless", "ru": "благословение", "stems": ["благослов"],
     "gloss": "благословить", "evidence": ["1En.1.1"]}
  ],
  "status": "draft",
  "notes": "",
  "history": [{"date": "2026-11-03", "by": "claude", "change": "создано"}]
}
```

`evidence` — либо место `1En.c.v` (в этом стихе должна стоять эта лемма: в `morph/enoch`, если разметка главы есть, иначе в корпусе), либо строка `Dillmann: Jer. 7,34`. Ссылка Дильмана должна быть в тексте того смысла статьи, где есть геэзский пример. Ссылка без показанного места не считается: у каждого смысла хотя бы одно место 1 Еноха или такая цитата. Пустой список и посторонний вид строки — ошибка.

`kind`, `display`, `status` и запрет переводить `name` и `divine` — как у ВЗ.

## Перевод Еноха (`translations/1En/<ггг>.json`)

Та же схема, что у перевода главы ВЗ: `book`, `chapter`, `rules`, `status`, `verses` со `spans` (`t`, `w`, `k`, `s`, `g`, `x`), `omit`, `places`. `book` — `1En`. Файл лежит прямо в `translations/1En/`, не во вложенной папке. `w` — номера слов корпуса `e…`.

`s` — смысл из `decisions/geez` той леммы, которая стоит у слова в разметке. Если у слова несколько сегментов, смысл может относиться к любому из них. Приставки (ወ በ ለ ዘ እም и остальные коды приставки) пишутся как `k: fn`. Союз ወ (приставка `c`) передаётся как «и», как ve- в ВЗ; иначе нужна причина в `x` на этом служебном фрагменте.

Слово, у которого в `morph/enoch` статус не `checked`, в переводе даёт предупреждение, не ошибку. Имя и титул не переводятся и с исключением `x`. Слово без решения в `decisions/geez`, чужой смысл, основа, которой нет в русском `t`, и латинская форма не из `display` / `displayForms` — ошибки, как у ВЗ. `x` снимает несовпадение основы и отсутствующий смысл, но не перевод имени.

Пока в `translations/1En/` нет ни одной главы, на столе читалки строка «перевод не начат». Когда главы есть — «главы 1–3, 5»: сплошной ряд сжимается, пропуски остаются видимыми.
