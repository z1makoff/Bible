# Устройство данных

Справка для подготовки глав. Правила перевода — в [ПРАВИЛА.md](ПРАВИЛА.md); этот файл описывает только, где и в каком виде всё хранится.

## Папки

| Папка | Что внутри | Кто меняет |
|---|---|---|
| `sources/` | Скачанные исходники и их паспорта (`passport.json`: лицензия, версия, SHA-256) | никто — только `tools/fetch_sources.py` |
| `corpus/` | Корпус, собранный из исходников. Не хранится в git: пересобирается командой `python tools/build_corpus.py` | только сборка |
| `decisions/lexicon/` | Словарь решений: один файл на словарное слово | Claude, с подтверждения пользователя |
| `translations/ot/<Книга>/<ггг>.json` | Перевод главы, по словам | Claude |
| `interpretations/` | Трактовки: один файл на трактовку | Claude, только с проверенным источником |
| `user/` | Решения и заметки пользователя из читалки | читалка |
| `tools/` | Скрипты: загрузка, сборка, проверка | — |

## Корпус (`corpus/`)

- `ot/books.json` — 39 книг: `id` (OSIS), русское название, число глав.
- `ot/<Книга>/<ггг>.json` — глава. У стиха: `ref` (`Gen.1.1`), `n`, `words`, `syn` (синодальные стихи), иногда `break` (`pe`/`samekh` — масоретские разделы).
- Слово: `id` (номер слова в OSHB, уникален во всём ВЗ), `text`, `tr` (механическая транслитерация), `lang` (`H` — еврейский, `A` — арамейский), `segs` (морфемы: `t`, `lemma`, `prefix`, `morph`), а также `maqqef`, `ketiv` и `qere` (список прочитываемых слов), `sourceNote`.
- `syn`: `{c, v, text, exact}`. `exact: false` — границы стихов не совпадают.
- `ot/synodal-only.json` — стихи, которые есть только в Синодальном (из Септуагинты).
- `lexemes.json` — словарные слова по ключу OSHB (`1254a`, `430`): еврейская форма, транслитерация, часть речи, число употреблений, статьи BDB, Strong и STEPBible. Это **аннотации**, а не доказательство.
- `occurrences.json` — для каждого ключа список `[стих, id слова]`.
- `build-report.json` — что не удалось сопоставить при сборке.

## Словарь решений (`decisions/lexicon/<ключ>.json`)

```json
{
  "key": "7307",
  "kind": "word",
  "display": "ruach",
  "senses": [
    {"id": "wind", "ru": "ветер", "stems": ["ветр", "ветер"],
     "gloss": "движение воздуха", "evidence": ["Gen.8.1", "Exod.10.13"]}
  ],
  "status": "draft",
  "notes": "",
  "history": [{"date": "2026-10-17", "by": "claude", "change": "создано"}]
}
```

- `kind`: `word` (обычное слово), `name` (имя человека, место, народ), `divine` (имя или титул божества), `function` (служебное слово).
- `display` — латинская форма для текста, когда слово не переводится (правила, раздел 2). Для `name` и `divine` слово никогда не переводится.
- `senses` — засвидетельствованные значения. `ru` — русское слово для этого значения, одно на всю Библию (раздел 3). `stems` — основы, по которым проверка узнаёт это слово в любом падеже. `evidence` — места, где значение видно.
- `status`: `draft` (подготовлено Claude) или `approved` (подтверждено пользователем).

## Перевод главы (`translations/ot/<Книга>/<ггг>.json`)

```json
{
  "book": "Gen", "chapter": 1, "rules": "1.0", "status": "draft",
  "verses": [
    {"n": 1,
     "spans": [
       {"t": "В начале", "w": ["01xeN"], "s": "beginning", "g": "Конструкция допускает: «В начале…» или «В начале того, как…»"},
       {"t": "создал", "w": ["01Nvk"], "s": "create"},
       {"t": "Elohim", "w": ["01TyA"], "k": "lat"},
       {"t": "небеса", "w": ["01TSc"], "s": "sky"},
       {"t": "и", "w": ["01k5P"], "k": "fn"},
       {"t": "землю", "w": ["01nPh"], "s": "land"},
       {"t": ".", "k": "p"}
     ],
     "omit": {"01vuQ": "et"},
     "places": {"01TyA": {"fits": [], "why": "Имя божества — не переводится (правила, раздел 2)"}}
    }
  ]
}
```

- `spans` — русский текст стиха по порядку. У каждого фрагмента: `t` (текст), `w` (номера еврейских слов; одно слово может дать несколько фрагментов, например «и» + «ruach»).
- `k` — вид фрагмента: не указан — перевод; `lat` — слово оставлено в транслитерации; `fn` — служебное слово или приставка («и», «в»); `ins` — вставлено ради русской грамматики, показывается серым; `p` — знак препинания.
- `s` — какое значение из словаря решений использовано. Обязательно для перевода.
- `g` — грамматический выбор (◇): какие разборы конструкции возможны.
- `x` — исключение из словаря решений в этом месте, с причиной (раздел 3).
- `omit` — еврейские слова, которые не дают русского слова, с причиной (`et` — метка прямого дополнения).
- `places` — разбор места для карточки: `fits` — какие значения подходят здесь, `why` — почему переведено или нет.

## Трактовки (`interpretations/<id>.json`)

```json
{
  "id": "biglino-elohim",
  "tradition": "Мауро Бильино",
  "lemmas": ["430"],
  "places": ["Gen.1.1"],
  "claim": "Пересказ утверждения без усиления",
  "source": {"kind": "book", "title": "…", "edition": "…", "page": "…", "checked": "2026-10-17"},
  "support": [
    {"claim": "Отдельное ключевое утверждение", "grade": "compatible",
     "for": ["Gen.1.26"], "against": ["Deut.4.35"], "note": "…"}
  ]
}
```

`grade` — шкала из правил, раздел 6: `entailed`, `strong`, `supported`, `plausible`, `compatible`, `speculative`, `contradicted`. В интерфейсе показываются только русские названия.

## Проверка

`python tools/check.py` — проверяет все решения, переводы и трактовки по правилам. Глава считается готовой, только если проверка проходит без ошибок.
